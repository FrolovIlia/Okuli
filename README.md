# Oculi - Тренировка зрения 👁️

Kotlin Multiplatform приложение для улучшения зрения и снятия цифрового напряжения глаз.

## 🎯 О проекте

Oculi - это персональный цифровой тренер для здоровья ваших глаз. Приложение использует доказанные методики (правило 20-20-20, упражнения для аккомодации, пальминг) для профилактики и улучшения зрения.

## ✨ Возможности

### 🆓 Бесплатные функции
- 2 базовых упражнения для глаз
- Умные напоминания о перерывах
- Проверка остроты зрения
- Базовая статистика прогресса
- Рекламная поддержка

### 💎 Премиум (подписка)
- Все упражнения (8+)
- Расширенная статистика и аналитика
- Персональные планы тренировок
- Без рекламы
- Приоритетная поддержка

## 🎮 Упражнения

### Преследуй цель
- **Тип**: Тренировка аккомодации
- **Описание**: Слежение за движущимся объектом
- **Длительность**: 2 минуты
- **Эффект**: Улучшение гибкости хрусталика

### Фокус-сдвиг
- **Тип**: Чередование ближнего/дальнего зрения
- **Описание**: Перефокусировка между экраном и удаленными объектами
- **Длительность**: 3 минуты
- **Эффект**: Снятие цифрового напряжения глаз

### Пальминг
- **Тип**: Расслабление глаз
- **Описание**: Техника полного затемнения и релаксации
- **Длительность**: 5 минут
- **Эффект**: Снятие усталости, улучшение кровообращения

### Восьмерки
- **Тип**: Улучшение подвижности глазных мышц
- **Описание**: Движение глаз по траектории восьмерки
- **Длительность**: 2 минуты
- **Эффект**: Укрепление глазодвигательных мышц

### Цифровая гимнастика
- **Тип**: Снятие цифрового напряжения
- **Описание**: Комплекс упражнений для пользователей гаджетов
- **Длительность**: 4 минуты
- **Эффект**: Профилактика компьютерного зрительного синдрома
