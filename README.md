# Backy - Тренировка осанки

Kotlin Multiplatform приложение для укрепления шеи и спины и снятия напряжения.

## 🎯 О проекте

Backy - это персональный цифровой тренер для здоровья вашей Спины и шеи. 

## ✨ Возможности

### 🆓 Бесплатные функции
- Базовых упражнения для спины и шеи
- Напоминания о занятиях
- Проверка гибкости спиты и шеи
- Базовая статистика прогресса

## 🛠 Технологический стек

### Frontend
- **Kotlin Multiplatform** (Android + iOS)
- **Jetpack Compose** / **SwiftUI**
- **Clean Architecture** + **MVVM**
- **moko-resources** для локализации

### Backend & Infrastructure
- **Firebase** (Auth, Firestore, Functions, Analytics)
- **Yandex.Рекламная сеть**

## 💰 Монетизация

### Модель
- **Бесплатно**: базовые функции + реклама

## 👥 Команда

Разрабатывается независимым разработчиком с фокусом на качество и пользовательский опыт.

## 🏗 Архитектура проекта

``
composeApp/src/commonMain/kotlin/com/pixelrabbit/backy/
├── domain/
│   ├── models/          # Модели данных
│   ├── repositories/    # Интерфейсы репозиториев  
│   └── use_cases/       # Use Cases
├── data/
│   └── repositories/    # Реализации репозиториев
├── presentation/
│   ├── screens/         # Все экраны приложения
│   ├── theme/           # Тема и стили
│   └── components/      # Переиспользуемые компоненты
├── di/                  # Dependency Injection
├── utils/               # Вспомогательные утилиты
└── backyApp.kt         # Главный компонент
``


### Многослойная архитектура (composeApp)
- **Presentation** - UI, ViewModels, навигация
- **Domain** - Use Cases, модели, репозитории
- **Data** - локальные и удаленные источники данных
- **DI** - управление зависимостями

## 🚀 Быстрый старт

### Требования
- Android Studio Hedgehog или новее
- JDK 17+
- Firebase проект
- Аккаунты: Яндекс.Реклама

### Установка
``bash
git clone [repository-url]
cd backy
./gradlew build
``
